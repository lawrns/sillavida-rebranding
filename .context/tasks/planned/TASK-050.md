# Implement "Vida Score" Product Comparison Tool

## Description
This task involves creating a new "Vida Score" product comparison tool that helps customers evaluate and compare ergonomic chairs based on how they enhance different aspects of life. Unlike traditional feature comparison tools that focus on technical specifications, the "Vida Score" will rate products on wellness categories like "Comfort Diario" (Daily Comfort), "Salud Postural" (Postural Health), "Productividad" (Productivity), and "Durabilidad" (Durability). This tool will help customers make more informed decisions based on their specific wellbeing priorities, reinforcing the "investing in yourself" theme.

## Objectives
- Create a "Vida Score" rating system for evaluating chairs on wellness categories
- Develop a visual comparison tool that displays scores for different products
- Implement filtering based on wellness priorities (e.g., "prioritize postural health")
- Design an intuitive interface that makes comparison easy and informative
- Ensure the tool visually aligns with the new color palette and typography
- Incorporate "Vida" theme elements in the tool design
- Make the tool responsive and accessible across all device sizes
- Implement the tool for both category pages and individual product pages
- Maintain compatibility with both static product data and Shopify product data

## Steps
1. Define the "Vida Score" rating criteria for each wellness category
2. Create a scoring methodology for evaluating products
3. Design the comparison tool interface using the new color palette and typography
4. Incorporate "Vida" theme elements in the tool design
5. Implement the scoring system for the existing product catalog
6. Create a new component for the comparison tool
7. Implement the component with proper responsive behavior
8. Add filtering functionality based on wellness priorities
9. Integrate the tool with both static product data and Shopify product data
10. Add the tool to category pages and individual product pages
11. Implement proper ARIA attributes for accessibility
12. Test the tool across different browsers and devices
13. Verify that the tool effectively helps customers compare products based on wellness benefits
