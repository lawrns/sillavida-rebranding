# Create "Por qué invertir en una silla ergonómica" Educational Section

## Description
This task involves creating a new educational section titled "Por qué invertir en una silla ergonómica" (Why invest in an ergonomic chair) for the SillaVida website. This section will provide valuable information about the health benefits, productivity improvements, and long-term value of investing in a quality ergonomic chair. The content will reinforce the "investing in yourself" theme and educate customers about how ergonomic chairs contribute to overall wellbeing, helping them make more informed purchase decisions.

## Objectives
- Create a comprehensive educational section about ergonomic chair benefits
- Develop content that connects ergonomic features to specific health benefits
- Include visual elements that illustrate proper posture and ergonomic principles
- Incorporate statistics and expert opinions about workplace ergonomics
- Structure the content in an engaging, easy-to-digest format
- Ensure the section visually aligns with the new color palette and typography
- Incorporate "Vida" theme elements throughout the section
- Make the section responsive and accessible across all device sizes
- Position the section strategically in the user journey to aid decision-making

## Steps
1. Research and compile information about ergonomic chair benefits and principles
2. Create a content outline for the educational section
3. Develop the main content categories (health benefits, productivity, long-term value)
4. Write engaging, informative copy that emphasizes the "investing in yourself" theme
5. Source or create illustrations that demonstrate proper posture and ergonomic principles
6. Design the section layout using the new color palette and typography
7. Incorporate "Vida" theme elements into the design
8. Create a new component for the educational section
9. Implement the component with proper responsive behavior
10. Add the component to the appropriate pages (homepage, category pages, or dedicated page)
11. Ensure the section is accessible and meets WCAG 2.1 AA standards
12. Test the section across different browsers and devices
13. Verify that the content effectively communicates the value of investing in ergonomic chairs
