# TASK-086: Redesign ProductCard Component (Hbada Clone Redesign)

## Description
This task involves redesigning the `ProductCard.tsx` component (and any variants like `ShopifyProductCard.tsx` if used) to align with the Hbada clone site's product card styling. This typically features clean layouts, clear typography for product name and price, and subtle hover effects, using the new black/white/red color palette.

## Objectives
- Update the product card's background, text colors, and border styles to match the clone's design (likely white/light gray backgrounds, dark text, potentially red accents for price or sale badges).
- Ensure product images are displayed clearly and maintain aspect ratio.
- Style product names and prices using the updated typography and color scheme.
- Redesign any badges (e.g., "Sale," "New") to use the new red accent color.
- Update hover effects to be subtle and consistent with the clone's design, using the new theme colors.
- Adjust padding, spacing, and overall dimensions of the product card to match the clone.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact styling of its product cards (layout, image treatment, text styles, price display, badges, hover effects, spacing).
2.  **Modify `ProductCard.tsx` (and variants):**
    *   Update the card's container styling (e.g., `bg-background`, `border border-border`, `rounded-lg`, `shadow-card`).
    *   Ensure product image containers are styled appropriately.
    *   Update text classes for product names (e.g., `text-foreground font-heading`) and prices (e.g., `text-primary font-semibold` if red is primary, or `text-destructive` if red is for sale prices).
    *   Restyle any sale or promotional badges using the new red accent color (e.g., `bg-primary text-primary-foreground`).
    *   Implement hover effects (e.g., slight shadow change `hover:shadow-card-hover`, subtle border color change) using the new theme's semantic classes.
    *   Adjust internal padding and margins to match the clone's product card layout.
3.  **Test Responsiveness:** Verify that product cards display correctly in grid layouts on various screen sizes.
4.  **Test Functionality:** Ensure product links and any interactive elements on the card (e.g., quick view button if present) are functional.
