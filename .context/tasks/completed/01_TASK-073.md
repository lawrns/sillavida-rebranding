# Apply Global Styles from Clone Site

## Description
This task involves updating the global CSS and base styling configuration of the live SillaVida site (http://sillavida.mx) to match the design system established in the SillaVida 2.0 clone site. This includes typography, color palette, base element styles, and potentially Tailwind CSS configuration if applicable.

## Objectives
- Implement the color palette defined in the clone site's Tailwind config and `globals.css` (Primary: #1DDBA6, Secondary: #28A76F, Gold: #D4AF37, Cream: #FDFBD4, Neutrals) across the live site.
- Implement the typography system from the clone site: Montserrat for headings, Roboto for body text, using the specified font sizes, weights, and line heights defined in the clone's `globals.css`.
- Update base HTML element styles (body, h1-h6, p, links) to match the clone site's `globals.css`.
- Ensure consistent spacing rules are applied based on the clone site's design system (refer to `branding_design_base_report.md`).
- Configure Tailwind CSS (if used in the live site) to reflect the clone site's theme extensions (colors, fonts, spacing, borderRadius, animations).

## Steps
1.  **Review Clone Site Styles:** Analyze the `tailwind.config.ts` and `app/globals.css` files from the SillaVida 2.0 clone site (`/home/ubuntu/sillavida_clone/sillavida/`) and the `branding_design_base_report.md`.
2.  **Identify Live Site Global Styling Files:** Locate the primary files controlling global CSS, base styles, and Tailwind configuration (if applicable) in the live site's codebase.
3.  **Update Color Variables/Configuration:** Modify the live site's CSS variables or Tailwind color configuration to precisely match the clone site's palette (Primary, Secondary, Accents, Neutrals, utility colors).
4.  **Update Typography Configuration:** Ensure the correct fonts (Montserrat, Roboto) are loaded and applied. Update CSS rules or Tailwind font configuration to match the clone's font families, sizes, weights, and line heights for headings and body text.
5.  **Update Base Element Styles:** Modify the global CSS rules for `body`, `h1`-`h6`, `p`, `a`, etc., to align with the styles defined in the clone's `globals.css`.
6.  **Apply Spacing System:** If using Tailwind, update the spacing configuration. Ensure consistent use of margins and padding according to the clone's spacing scale.
7.  **Integrate Animations (Optional but Recommended):** Consider integrating the subtle animations (keyframes and animation utilities) defined in the clone's Tailwind config for enhanced UI polish.
8.  **Test:** Verify that global styles are applied correctly across different pages and components of the live site. Check for visual consistency and ensure no existing functionality is broken.
