# TASK-083: Redesign Header/Navbar Components (Hbada Clone Redesign)

## Description
This task focuses on redesigning the `Navbar.tsx` and `VidaNavbar.tsx` components to match the Hbada clone's header appearance (typically a white or light background with dark text and red accents for active links or calls to action), ensuring responsiveness and functionality are maintained.

## Objectives
- Update the background color of the header/navbar to align with the clone's design (likely white or a very light neutral).
- Ensure navigation links, logo, and icons use colors that provide good contrast and match the new theme (dark text, red for active/accented items).
- Verify that dropdown menus and mobile navigation elements are also restyled consistently.
- Ensure all interactive elements (links, buttons, cart badge) use semantic color classes and function correctly.
- Adjust padding, spacing, and layout within the header components to match the clone's visual structure.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact styling of its header (background, text colors, link styles, active states, spacing, logo treatment).
2.  **Modify `Navbar.tsx` and `VidaNavbar.tsx`:**
    *   Update the main container's background class (e.g., to `bg-background` or `bg-neutral-white`).
    *   Change text color classes for navigation links to a dark neutral (e.g., `text-foreground` or `text-neutral-darkgray`).
    *   Style active navigation links or highlighted items with the primary accent color (e.g., `text-primary` if red is primary, or `text-destructive` if red is used for accents).
    *   Restyle icons (user, cart) to match the new theme.
    *   Update the cart badge styling to use the new accent colors.
    *   Ensure dropdown menus inherit the new theme correctly (background, text, hover states).
    *   Adjust padding and margins within the header elements to match the clone's spacing.
3.  **Responsive Design:** Verify the redesigned header looks and functions correctly on various screen sizes (desktop, tablet, mobile), paying attention to the mobile menu's styling.
4.  **Test Functionality:** Ensure all links, buttons, dropdowns, and the mobile menu toggle work as expected.

## Progress

- Maintained primary (red) color for active states and accents
- Updated dropdown and mobile menus to match the new color scheme
