# Redesign Product Card Components

## Description
This task involves redesigning the product card components used in product listings and potentially other areas (e.g., related products, featured sections) of the live SillaVida site. The goal is to match the visual style and information hierarchy of the product cards found in the SillaVida 2.0 clone site. The overview mentioned several potential components: `src/components/ProductCard.tsx`, `src/components/ProductCardSimple.tsx`, and `src/components/ShopifyProductCard.tsx`. This task may involve consolidating or standardizing these components.

## Objectives
- Update the layout and styling of the primary product card component(s) used in listings to match the clone site's design (refer to clone site preview, clone component `components/ui/product-card.tsx`, and `branding_design_base_report.md`).
- Apply the correct color palette (backgrounds, text colors, button styles, badges) as defined in TASK-072.
- Apply the correct typography (fonts, sizes, weights for title, price, reviews) as defined in TASK-072.
- Ensure the card displays the product image, title, price (including original price/discount if applicable), rating/reviews, and a call-to-action button (e.g., "Ver producto" or "Añadir al carrito") consistent with the clone design.
- Style any badges (e.g., "NUEVO", "POPULAR", discount percentage) according to the clone design.
- Implement responsive behavior consistent with the clone site's design.
- Ensure the component correctly receives and displays data passed via props (likely Shopify product objects).
- Ensure links and buttons navigate/function correctly.

## Steps
1.  **Review Clone Product Card Design:** Analyze the product card implementation in the SillaVida 2.0 clone site preview (e.g., on the `/productos` page if available, or related products section) and the code in `components/ui/product-card.tsx`.
2.  **Analyze Live Site Components:** Examine the code for `src/components/ProductCard.tsx`, `src/components/ProductCardSimple.tsx`, and `src/components/ShopifyProductCard.tsx`. Determine which is the primary component used in listings and if consolidation is feasible.
3.  **Apply Layout Changes:** Modify the JSX structure and Tailwind CSS classes within the chosen/refactored product card component to replicate the clone card's layout (image container, text content arrangement, button placement).
4.  **Apply Styling:** Update Tailwind classes to use the correct background colors, text colors, button styles, badge styles, font styles, padding, margins, borders, shadows, hover effects, etc., based on the clone design and the global styles defined in TASK-072.
5.  **Style Card Content:** Ensure the product image, title, price, rating, and CTA are styled according to the clone design.
6.  **Implement Responsive Design:** Add/modify Tailwind responsive prefixes to ensure the card adapts correctly to different screen sizes within grid layouts.
7.  **Verify Data Integration:** Confirm that the component correctly renders data from the Shopify product object prop. **Do not change the expected prop structure.**
8.  **Test:** Perform thorough testing on product listing pages. Verify visual consistency across multiple cards, responsiveness within the grid, data display accuracy, and link/button functionality. Ensure no existing Shopify data integrations are broken.
