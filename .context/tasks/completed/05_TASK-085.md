# TASK-085: Redesign Homepage HeroSlider Component (Hbada Clone Redesign)

## Description
This task focuses on redesigning the `HeroSlider.tsx` component on the homepage to align with the Hbada clone's hero section styling. This typically involves ensuring the background images/videos are prominent, text overlays are clear and use the new theme colors (black/white/red), and call-to-action (CTA) buttons are styled according to the new red accent theme.

## Objectives
- Update text overlay colors (headings, subheadings) to use high-contrast neutrals (white text on dark images, dark text on light images) from the new palette.
- Restyle CTA buttons within the hero slides to use the primary red accent color for backgrounds and contrasting text (e.g., white text).
- Ensure any background overlays or gradients use the new theme's neutral or accent colors appropriately, avoiding legacy teal/green.
- Verify that slider navigation elements (dots, arrows) are styled consistently with the new theme.
- Adjust typography, text sizes, padding, and button styles to match the clone's hero section.
- Ensure responsiveness and that the hero slider adapts correctly to different screen sizes.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact styling of its hero section (text styles, button styles, overlay colors, navigation element styles, overall layout and spacing).
2.  **Modify `HeroSlider.tsx`:**
    *   Inspect the component for any hardcoded colors in text overlays, button styling, or background elements.
    *   Update text classes to use appropriate neutrals (e.g., `text-neutral-white`, `text-neutral-darkgray`) based on the slide's background imagery for optimal contrast.
    *   Change CTA button styling to use the new primary red accent (e.g., `bg-primary text-primary-foreground` or `bg-destructive text-destructive-foreground` if red is mapped to destructive, and primary-foreground is white/light).
    *   If background overlays are used, ensure they use neutral tones or subtle accents from the new palette, not the old teal/green.
    *   Restyle slider navigation controls (arrows, pagination dots) to match the new theme (e.g., red accents or dark neutrals).
    *   Adjust font sizes, weights, letter spacing, and padding for text elements and buttons to match the clone.
3.  **Responsive Design:** Test the hero slider thoroughly on desktop, tablet, and mobile views to ensure it scales and reflows correctly while maintaining the new design integrity.
4.  **Test Functionality:** Confirm that the slider transitions, navigation, and CTA button links work as expected.
