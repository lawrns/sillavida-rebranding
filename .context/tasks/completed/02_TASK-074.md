# Redesign Header/Navbar Components

## Description
This task involves redesigning the main site header/navigation components (`src/components/Navbar.tsx` and `src/components/VidaNavbar.tsx`) of the live SillaVida site to match the visual style, layout, and responsiveness of the header found in the SillaVida 2.0 clone site.

## Objectives
- Update the layout and styling of `Navbar.tsx` and `VidaNavbar.tsx` to match the clone site's header design (refer to clone site preview and `branding_design_base_report.md`).
- Apply the correct color palette (primary, secondary, neutrals) as defined in TASK-072.
- Apply the correct typography (Montserrat for logo/headings, Roboto for links) as defined in TASK-072.
- Ensure navigation links, logo placement, category dropdowns (if applicable), search icon (if applicable), login/account icon, and cart icon match the clone's header structure and styling.
- Implement responsive behavior (e.g., mobile menu/hamburger icon) consistent with the clone site's design.
- Ensure all interactive elements (links, buttons, icons) are functional and maintain existing routing/actions (e.g., opening cart, navigating to login).

## Steps
1.  **Review Clone Header Design:** Analyze the header implementation in the SillaVida 2.0 clone site preview (http://3000-ivwqmcfid1l53230i8oxt-b721aa97.manus.computer) and relevant code (likely within `app/layout.tsx` or a dedicated header component in the clone).
2.  **Analyze Live Site Components:** Examine the code for `src/components/Navbar.tsx` and `src/components/VidaNavbar.tsx` in the live site codebase.
3.  **Apply Layout Changes:** Modify the JSX structure and Tailwind CSS classes within `Navbar.tsx` and `VidaNavbar.tsx` to replicate the clone header's layout (logo position, navigation item arrangement, icon placement).
4.  **Apply Styling:** Update Tailwind classes to use the correct background colors, text colors, font families, font sizes, padding, margins, and border styles based on the clone design and the global styles defined in TASK-072.
5.  **Implement Responsive Design:** Add/modify Tailwind responsive prefixes (e.g., `md:`, `lg:`) to ensure the header adapts correctly to different screen sizes, including the implementation of a mobile navigation menu if present in the clone design.
6.  **Verify Interactivity:** Confirm that all links navigate correctly, the cart icon reflects the cart state (from `CartContext.tsx`), and any dropdowns or interactive elements function as expected, preserving existing logic.
7.  **Test:** Perform thorough testing on various screen sizes (desktop, tablet, mobile) and browsers. Verify visual consistency, responsiveness, and functionality. Ensure no existing Shopify data integrations are broken.
