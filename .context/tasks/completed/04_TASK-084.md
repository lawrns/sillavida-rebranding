# TASK-084: Redesign Footer Component (Hbada Clone Redesign)

## Description
This task involves redesigning the `Footer.tsx` component to align with the Hbada clone's footer appearance. This typically means a dark background (black or very dark gray) with light-colored text (white or light gray) and potentially red accents for certain links or calls to action.

## Objectives
- Update the background color of the footer to a dark neutral (e.g., `bg-neutral-darkgray` or `bg-black`).
- Ensure text, links, and headings within the footer use light colors for contrast (e.g., `text-neutral-white` or `text-neutral-lightgray`).
- Style any specific accent elements (e.g., social media icons, newsletter signup button) according to the new theme, potentially using the primary red accent.
- Verify consistent styling across all footer sections (e.g., link columns, copyright notice).
- Adjust padding, spacing, and layout within the footer to match the clone's visual structure.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact styling of its footer (background color, text colors, link styles, spacing, column layout, any specific graphical elements).
2.  **Modify `Footer.tsx`:**
    *   Update the main container's background class (e.g., to `bg-neutral-darkgray` or a similar dark color from the updated palette).
    *   Change text color classes for headings, paragraphs, and links to a light neutral (e.g., `text-neutral-offwhite` or `text-gray-300`).
    *   Style link hover/focus states appropriately for a dark background.
    *   If the clone uses red accents in the footer, apply `text-primary` or `bg-primary` (if red is primary) to the relevant elements.
    *   Adjust padding, margins, and column layouts to match the clone's footer structure.
3.  **Test Functionality:** Ensure all links in the footer are working correctly.
