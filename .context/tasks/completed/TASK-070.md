# Implement Dynamic Hero Slider using Shopify Metaobjects

## Description
Update the website's hero slider component to dynamically fetch and display slides based on a custom "Hero Slide" Metaobject definition in Shopify. This allows managing slider content (product featured, image, details, order) directly within Shopify, providing a more robust and maintainable solution compared to using Alt Text for a multi-product slider.

## Objectives
- Modify the hero slider React component (identify component if name is unknown).
- Implement a Shopify Storefront API query (GraphQL) to fetch "Hero Slide" Metaobject entries.
- Parse fetched data including product reference (for title and price), slide image URL, details text, and display order.
- Render slides dynamically using the fetched data.
- Ensure slides are displayed in the correct order based on the `display_order` field.

## Steps
1.  **Identify Component:** Locate the React component responsible for rendering the hero slider on the site (e.g., `HeroSlider.jsx`, or potentially within `ProductPage.jsx` or a homepage component).
2.  **Define GraphQL Query:** Construct the Storefront API GraphQL query to fetch `metaobjects` of type `hero_slide` (confirm handle generated by Shopify). Include fields for `display_order`, `slide_image` (as `image { url }`), `slide_details`, and the referenced `product_to_feature` (including its `handle`, `title`, and `priceRangeV2 { minVariantPrice { amount currencyCode } }`).
3.  **Integrate Query:** Integrate the GraphQL query into the component using the project's Shopify data fetching mechanism (e.g., Hydrogen's `useShopQuery`, Remix loader functions, or other API client methods).
4.  **Process Data:** In the component logic, retrieve the list of Metaobject entries from the query result. Sort the entries numerically based on the `display_order` field.
5.  **Update Rendering:** Modify the component's rendering logic to iterate over the sorted Metaobject entries. For each entry, render a slide.
6.  **Render Slide Content:** Within each slide, display:
    *   The image using the `slide_image.image.url`.
    *   The product title using `product_to_feature.title`.
    *   The product price using `product_to_feature.priceRangeV2.minVariantPrice.amount` and `currencyCode`.
    *   The details text from `slide_details` (parse if needed, e.g., split by newline).
7.  **Styling:** Apply necessary CSS styles to ensure the slider matches the desired design.
8.  **Testing:** Test the implementation thoroughly by creating sample "Hero Slide" Metaobject entries in Shopify and verifying they display correctly in the slider, including order, content, and pricing.
