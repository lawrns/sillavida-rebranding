# Redesign Footer Component

## Description
This task involves redesigning the main site footer component (`src/components/Footer.tsx`) of the live SillaVida site to match the visual style, layout, and content structure of the footer found in the SillaVida 2.0 clone site.

## Objectives
- Update the layout and styling of `src/components/Footer.tsx` to match the clone site's footer design (refer to clone site preview and `branding_design_base_report.md`).
- Apply the correct color palette (backgrounds, text colors, link colors) as defined in TASK-072.
- Apply the correct typography (fonts, sizes, weights) for headings, links, and text within the footer, as defined in TASK-072.
- Ensure the content structure (e.g., columns for links, newsletter signup, social media icons, copyright notice) matches the clone site's footer.
- Implement responsive behavior consistent with the clone site's design.
- Ensure all links are functional and point to the correct destinations.

## Steps
1.  **Review Clone Footer Design:** Analyze the footer implementation in the SillaVida 2.0 clone site preview (http://3000-ivwqmcfid1l53230i8oxt-b721aa97.manus.computer) and relevant code (likely within `app/layout.tsx` or a dedicated footer component in the clone).
2.  **Analyze Live Site Component:** Examine the code for `src/components/Footer.tsx` in the live site codebase.
3.  **Apply Layout Changes:** Modify the JSX structure and Tailwind CSS classes within `Footer.tsx` to replicate the clone footer's layout (e.g., grid/flex columns, content arrangement).
4.  **Apply Styling:** Update Tailwind classes to use the correct background colors, text colors, link styles, font styles, padding, margins, etc., based on the clone design and the global styles defined in TASK-072.
5.  **Update Content Structure:** Adjust the content within the footer (link lists, headings, text blocks, icons) to match the clone's structure. Ensure links are correct.
6.  **Implement Responsive Design:** Add/modify Tailwind responsive prefixes (e.g., `md:`, `lg:`) to ensure the footer adapts correctly to different screen sizes.
7.  **Verify Interactivity:** Confirm that all links navigate correctly and any interactive elements (like a newsletter signup form, if present in the clone design) function as expected.
8.  **Test:** Perform testing on various screen sizes and browsers. Verify visual consistency, responsiveness, and link functionality.
