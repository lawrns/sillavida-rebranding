# Redesign Product Detail Page Image Gallery

## Description
This task involves redesigning the product image gallery component (`src/components/product/ProductGallery.tsx`) used on the product detail page of the live SillaVida site. The goal is to match the visual style, layout, and functionality (thumbnails, zoom, navigation) of the gallery found in the SillaVida 2.0 clone site (`components/product-gallery.tsx`).

## Objectives
- Update the layout and styling of `src/components/product/ProductGallery.tsx` to match the clone site's gallery design.
- Implement the thumbnail navigation below the main image.
- Implement the main image display with aspect ratio control and potential zoom-on-hover/click functionality as seen in the clone.
- Implement the navigation arrows (previous/next) overlaid on the main image.
- Apply the correct color palette and styling for borders, backgrounds, and icons as defined in TASK-072.
- Ensure the component correctly receives and displays product images passed via props (likely from the parent `ProductPage.tsx`).
- Ensure the gallery is responsive and adapts well to different screen sizes.

## Steps
1.  **Review Clone Gallery Design:** Analyze the product gallery implementation in the SillaVida 2.0 clone site preview (e.g., on a product page) and the code in `components/product-gallery.tsx`.
2.  **Analyze Live Site Component:** Examine the code for `src/components/product/ProductGallery.tsx` in the live site codebase.
3.  **Apply Layout Changes:** Modify the JSX structure and Tailwind CSS classes within `ProductGallery.tsx` to replicate the clone gallery's layout (main image container, thumbnail strip).
4.  **Implement Thumbnail Navigation:** Ensure thumbnails are displayed horizontally and clicking a thumbnail updates the main image.
5.  **Implement Main Image Display & Zoom:** Style the main image container. Implement zoom functionality (e.g., on click or hover, potentially scaling the image or using a magnifier effect) if present and desired from the clone design.
6.  **Implement Arrow Navigation:** Add previous/next buttons overlaid on the main image and ensure they cycle through the images correctly.
7.  **Apply Styling:** Update Tailwind classes for borders (e.g., active thumbnail), backgrounds, icon styling, padding, margins, etc., based on the clone design and TASK-072.
8.  **Implement Responsive Design:** Add/modify Tailwind responsive prefixes to ensure the gallery adapts correctly (e.g., thumbnail scrolling on mobile).
9.  **Verify Data Integration:** Confirm that the component correctly renders the product images passed as props. **Do not change the expected prop structure.**
10. **Test:** Perform thorough testing on various screen sizes and browsers. Verify visual consistency, thumbnail navigation, arrow navigation, zoom functionality (if implemented), and responsiveness.
