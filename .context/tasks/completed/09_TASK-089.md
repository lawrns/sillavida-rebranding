# TASK-089: Redesign Product Features/Specifications Tabs (Hbada Clone Redesign)

## Description
This task involves redesigning the tabbed interface (likely `ProductFeatures.tsx` or similar, used within `ProductPage.tsx`) that displays product features, specifications, reviews, etc., on the Product Detail Page (PDP). The goal is to align its styling with the Hbada clone design, using the new black/white/red color palette.

## Objectives
- Restyle the tab buttons (active and inactive states) to match the clone design (e.g., red accent for active tab, neutral colors for inactive tabs).
- Ensure the tab panel content area has appropriate background and text colors consistent with the new theme.
- Update typography within the tab content (headings, lists, paragraphs) to align with the global styles.
- Adjust spacing, borders, and overall layout of the tab component to match the clone.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact styling of its PDP tabs (tab button appearance, active tab indication, panel styling, content typography).
2.  **Modify `ProductFeatures.tsx` (or the relevant tab component):**
    *   Update styling for tab buttons. Active tabs might use a red accent (`bg-primary text-primary-foreground` or `border-b-2 border-primary text-primary`). Inactive tabs should use neutral colors (e.g., `text-neutral-darkgray hover:text-foreground`).
    *   Ensure the tab panel container has a clean background (e.g., `bg-background` or `bg-neutral-offwhite`).
    *   Update text styles within the tab content (headings, paragraphs, lists) to use semantic classes reflecting the new theme (e.g., `text-foreground`, `text-neutral-darkgray`).
    *   Adjust padding, margins, and borders for the tab buttons and panels to match the clone design.
3.  **Responsive Design:** Test the tab component on various screen sizes to ensure it remains usable and visually consistent.
4.  **Test Functionality:** Verify that clicking tabs correctly switches the displayed content panel. Ensure all content within the tabs is readable and correctly styled.
