# TASK-087: Redesign ProductPage Layout & Core Info (Hbada Clone Redesign)

## Description
This task focuses on redesigning the overall layout and core information section of the `ProductPage.tsx` component to align with the Hbada clone site's product detail page (PDP) structure. This typically involves a two-column layout (gallery on one side, info/actions on the other) with clean typography and prominent call-to-action buttons styled with the new black/white/red theme.

## Objectives
- Implement or adjust the main two-column layout for the PDP, ensuring the product gallery and product information/actions sections are correctly positioned.
- Restyle the product title, price, variant selectors, quantity input, and add-to-cart button to match the clone's design using the new color palette and typography.
- Ensure key information like SKU, availability, and short descriptions are presented clearly with appropriate styling.
- Update the styling of trust badges, shipping information, or return policy snippets if present in this section.
- Ensure the layout is responsive and adapts well to different screen sizes.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact layout of its PDP, including the arrangement of gallery and info sections, styling of product title, price, variant selectors, quantity input, add-to-cart button, and any other informational elements.
2.  **Modify `ProductPage.tsx` (and potentially child components handling specific info blocks):**
    *   Adjust the main page structure to achieve the desired two-column layout (e.g., using Flexbox or CSS Grid).
    *   Update text classes for the product title (e.g., `text-2xl font-heading text-foreground`), price (e.g., `text-xl font-semibold text-primary` or `text-destructive`), and descriptions (e.g., `text-neutral-darkgray`).
    *   Restyle form elements like variant dropdowns/swatches and quantity input to match the clone (e.g., using `border-border`, `bg-background`, `text-foreground`).
    *   Redesign the Add-to-Cart button to be prominent, using the primary red accent color (e.g., `bg-primary text-primary-foreground hover:bg-primary/90`).
    *   Style any secondary buttons (e.g., "Buy Now," "Add to Wishlist") with appropriate secondary or outline styles from the new theme.
    *   Ensure consistent spacing and padding around elements as per the clone design.
3.  **Responsive Design:** Test the PDP layout thoroughly on desktop, tablet, and mobile views. Ensure the two-column layout gracefully transitions to a single-column layout on smaller screens if appropriate, maintaining readability and usability.
4.  **Test Functionality:** Verify that variant selection, quantity changes, and the add-to-cart process work correctly. Ensure all Shopify data (title, price, variants, etc.) is accurately displayed.
