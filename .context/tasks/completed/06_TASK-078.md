# Redesign Product Detail Page Layout & Info Section

## Description
This task involves redesigning the main product detail page (`src/pages/ProductPage.tsx`) of the live SillaVida site. The focus is on implementing the layout structure seen in the SillaVida 2.0 clone site (specifically the side-by-side arrangement of the image gallery and product information) and restyling the product information section itself.

## Objectives
- Update the overall layout of `src/pages/ProductPage.tsx` to position the product gallery (TASK-078) and the product information section side-by-side on larger screens, similar to the clone site (`app/producto/[slug]/page.tsx`).
- Restyle the product information section within `src/pages/ProductPage.tsx` to match the clone site's design. This includes:
    - Product title styling.
    - Rating display (stars and review count link).
    - Price display (current price, original price, discount badge).
    - Short description styling.
    - Color/variant selection styling (if applicable).
    - Quantity selector styling.
    - "Add to Cart" and "Buy Now" button styling.
    - Shipping/guarantee information section styling (icons and text).
- Apply the correct color palette and typography as defined in TASK-072.
- Ensure the layout is responsive, stacking elements appropriately on smaller screens.
- Ensure all existing data fetching and display logic for product information (title, price, description, variants, stock, etc.) remains functional.
- Ensure interactive elements (quantity selector, variant selectors, add-to-cart button) function correctly and interact with the cart context.

## Steps
1.  **Review Clone Product Page Design:** Analyze the product page implementation in the SillaVida 2.0 clone site preview (e.g., `/producto/sillavida-e7-pro-silla-ergonomica-de-oficina`) and the code in `app/producto/[slug]/page.tsx`.
2.  **Analyze Live Site Page:** Examine the code for `src/pages/ProductPage.tsx` in the live site codebase.
3.  **Implement Side-by-Side Layout:** Modify the JSX structure and Tailwind CSS classes within `ProductPage.tsx` to create the two-column layout for the gallery and info sections on desktop/tablet screens, ensuring it stacks vertically on mobile.
4.  **Restyle Info Section Elements:** Update the Tailwind classes for the `h1` (title), rating elements, price display, description paragraph, variant selectors, quantity input/buttons, main action buttons, and shipping info section to match the clone's appearance and spacing.
5.  **Apply Global Styles:** Ensure colors, fonts, and spacing adhere to the standards set in TASK-072.
6.  **Implement Responsive Design:** Add/modify Tailwind responsive prefixes to ensure the layout and info section elements adapt correctly to different screen sizes.
7.  **Verify Data Integration:** Confirm that all product data fetched from Shopify is correctly displayed in the newly styled elements. **Do not change how data is fetched or accessed.**
8.  **Verify Interactivity:** Test variant selection, quantity changes, and the "Add to Cart" button functionality thoroughly, ensuring they interact correctly with the Shopify backend and cart context.
9.  **Test:** Perform thorough testing on various screen sizes and browsers. Verify visual consistency, responsiveness, data display accuracy, and interactive element functionality.
