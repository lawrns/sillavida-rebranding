# Redesign Product Detail Page Features/Specifications Section

## Description
This task involves redesigning the section(s) on the product detail page that display detailed features and specifications. The live site currently uses `src/components/ProductFeatures.tsx` and `src/components/ChairFeaturesComponent.tsx`. The goal is to consolidate and restyle this information presentation to match the tabbed interface used in the SillaVida 2.0 clone site (`app/producto/[slug]/page.tsx`).

## Objectives
- Implement a tabbed interface below the main product gallery/info section on `src/pages/ProductPage.tsx` to organize detailed information (e.g., "Características", "Especificaciones", "Reseñas").
- Restyle the content within each tab (Features, Specifications) to match the clone site's design (refer to clone preview and `app/producto/[slug]/page.tsx`).
- Apply the correct color palette and typography for tab triggers, tab content, headings, lists, and tables as defined in TASK-072.
- Ensure the layout within tabs is responsive.
- Integrate the data currently displayed by `src/components/ProductFeatures.tsx` and `src/components/ChairFeaturesComponent.tsx` into the new tabbed structure.
- If a reviews tab is included (as in the clone), ensure it integrates correctly with the review system (e.g., Judge.me, potentially requiring coordination with previous tasks related to reviews).

## Steps
1.  **Review Clone Tabs Design:** Analyze the tabbed section implementation in the SillaVida 2.0 clone site preview (product page) and the code in `app/producto/[slug]/page.tsx` (specifically the `<Tabs>` component usage).
2.  **Analyze Live Site Components:** Examine the code for `src/pages/ProductPage.tsx`, `src/components/ProductFeatures.tsx`, and `src/components/ChairFeaturesComponent.tsx` to understand how features/specs are currently displayed and where the data comes from.
3.  **Implement Tab Structure:** Modify `src/pages/ProductPage.tsx` to include a Tabs component (similar to the clone, potentially using a library like Radix UI Tabs if not already available) below the main product info section.
4.  **Create Tab Triggers:** Style the tab buttons ("Características", "Especificaciones", etc.) to match the clone design using styles from TASK-072.
5.  **Migrate & Style Content:**
    *   Move the logic/content for displaying features (likely from `ProductFeatures.tsx` or similar) into the "Características" tab content area. Restyle the presentation (e.g., list format, icons) to match the clone.
    *   Move the logic/content for displaying specifications (likely from `ChairFeaturesComponent.tsx` or similar) into the "Especificaciones" tab content area. Restyle the presentation (e.g., definition list, table) to match the clone.
    *   If implementing a "Reseñas" tab, integrate the review display component here.
6.  **Apply Styling:** Update Tailwind classes for the tab container, triggers, and content areas based on the clone design and TASK-072.
7.  **Implement Responsive Design:** Ensure the tabbed interface and its content adapt correctly to different screen sizes.
8.  **Verify Data Integration:** Confirm that all feature and specification data is correctly displayed within the tabs. **Do not change how this data is fetched or passed to the page/components.**
9.  **Test:** Perform thorough testing on various screen sizes and browsers. Verify visual consistency, tab functionality, content accuracy, and responsiveness.
