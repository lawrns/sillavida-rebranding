# TASK-088: Redesign ProductGallery Component (Hbada Clone Redesign)

## Description
This task focuses on redesigning the `ProductGallery.tsx` component on the Product Detail Page (PDP) to align with the Hbada clone site's product image gallery styling. This typically involves a main image display with thumbnails below or to the side, clear navigation controls, and potentially a zoom or lightbox feature, all styled with the new black/white/red theme.

## Objectives
- Ensure the main product image and thumbnails are displayed clearly and responsively.
- Style thumbnail navigation (active state, hover states) using the new theme colors (e.g., red border for active thumbnail).
- Update any gallery navigation controls (arrows for next/previous image) to match the clone's design and color scheme.
- If a zoom-on-hover or lightbox/modal view is implemented, ensure its styling is consistent with the new theme (e.g., modal background, close button).
- Adjust spacing, borders, and overall layout of the gallery to match the clone.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site to understand the exact styling of its product gallery (main image presentation, thumbnail layout and styling, navigation controls, zoom/lightbox behavior).
2.  **Modify `src/components/product/ProductGallery.tsx`:**
    *   Update styling for the main image container and thumbnail containers (e.g., borders, background if any).
    *   Style active thumbnails with a clear visual indicator using the new accent color (e.g., `border-primary` if red is primary).
    *   Restyle gallery navigation arrows (if present) using appropriate icons and colors from the new theme.
    *   If a zoom feature is present, ensure its UI elements are consistent.
    *   If a lightbox/modal is used for larger image views, style its background, close button, and navigation elements according to the new theme.
    *   Adjust padding and margins within the gallery components to match the clone's spacing.
3.  **Responsive Design:** Test the product gallery on various screen sizes, ensuring thumbnails and main image adapt correctly and remain usable.
4.  **Test Functionality:** Verify that thumbnail selection updates the main image, navigation controls work, and any zoom/lightbox features function as expected. Ensure all Shopify product image data is correctly displayed.
