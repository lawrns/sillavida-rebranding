# Redesign Homepage Hero Slider

## Description
This task involves redesigning the homepage hero slider component (`src/components/HeroSlider.tsx`) of the live SillaVida site to match the visual style and layout of the hero section found in the SillaVida 2.0 clone site, while ensuring it correctly displays data fetched from Shopify Metaobjects as per TASK-068.

## Objectives
- Update the layout and styling of `src/components/HeroSlider.tsx` to match the clone site's hero section design (refer to clone site preview and `branding_design_base_report.md`).
- Apply the correct color palette (backgrounds, text colors, button styles) as defined in TASK-072.
- Apply the correct typography (fonts, sizes, weights for title, description, details) as defined in TASK-072.
- Ensure the layout correctly displays the product image, title, details (parsed from Metaobject), and price (from linked product).
- Style the navigation elements (dots/arrows) and the call-to-action button ("Ver producto") to match the clone design.
- Implement responsive behavior consistent with the clone site's design.
- Ensure the component correctly fetches and displays data from the "Hero Slide" Shopify Metaobjects (as implemented in TASK-068 or subsequent fixes like TASK-071).
- Ensure the "Ver producto" button links correctly to the respective product page (`/product/:handle`).

## Steps
1.  **Review Clone Hero Design:** Analyze the hero section implementation in the SillaVida 2.0 clone site preview (http://3000-ivwqmcfid1l53230i8oxt-b721aa97.manus.computer) and relevant code (likely within `app/page.tsx` or a dedicated hero component in the clone).
2.  **Analyze Live Site Component:** Examine the code for `src/components/HeroSlider.tsx` in the live site codebase, paying attention to how it fetches and renders Metaobject data.
3.  **Apply Layout Changes:** Modify the JSX structure and Tailwind CSS classes within `HeroSlider.tsx` to replicate the clone hero section's layout (image position, text alignment, button placement).
4.  **Apply Styling:** Update Tailwind classes to use the correct background colors, text colors, button styles, font styles, padding, margins, etc., based on the clone design and the global styles defined in TASK-072.
5.  **Style Slide Content:** Ensure the product title, details (split by `|`), and price are styled according to the clone design.
6.  **Style Navigation & CTA:** Apply styles to slider navigation elements (dots/arrows) and the "Ver producto" button to match the clone.
7.  **Implement Responsive Design:** Add/modify Tailwind responsive prefixes to ensure the hero section adapts correctly to different screen sizes.
8.  **Verify Data Integration:** Confirm that the component continues to correctly fetch data from Shopify Metaobjects and that the product link uses the correct handle.
9.  **Test:** Perform thorough testing on various screen sizes and browsers. Verify visual consistency, responsiveness, data display, and button functionality. Ensure no existing Shopify data integrations are broken.
