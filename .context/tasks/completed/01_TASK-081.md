# TASK-081: Update Global Color Palette & Base Styles (Hbada Clone Redesign)

## Description
This task focuses on updating the global color palette and base styles of the SillaVida website to align with the Hbada clone design, which features a predominantly black, white, and red aesthetic. This involves modifying CSS custom properties and Tailwind configuration.

## Objectives
- Update CSS custom properties in `src/index.css` to reflect the new color palette (primary red, e.g., `#d71920`, and appropriate neutrals).
- Ensure `tailwind.config.js` correctly maps its theme colors to these new CSS custom properties.
- Verify that global typography (Montserrat for headings, Roboto for body, as per `CODEBASE_OVERVIEW.md`) is correctly defined and applied.
- Remove or comment out legacy teal/green color definitions from `src/index.css` and `tailwind.config.js` to avoid conflicts.
- Remove dark mode variables and functionality as requested.

## Steps
1.  **Analyze Clone Palette:** Re-confirm the exact primary red, secondary (if any), and neutral shades (blacks, whites, grays) used in the Hbada clone site. The `CODEBASE_OVERVIEW.md` suggests `#d71920` for the red.
2.  **Update `src/index.css`:**
    *   Modify the `--primary` CSS custom property to the target red (e.g., `356 75% 45%` for `#d71920`). Update `--primary-rgb` accordingly.
    *   Review and update other semantic roles like `--secondary`, `--accent`, `--ring`, `--destructive` if they need to align with the new red/black/white theme. For instance, `--ring` might use the new primary red.
    *   Adjust neutral color variables (`--background`, `--foreground`, `--card`, `--popover`, `--border`, `--input`, `--muted`) to match the clone's black/white/gray scheme.
    *   Comment out or remove the old teal/green definitions for `--primary: 162 73% 46%;` and `--secondary: 145 63% 42%;`.
    *   Ensure `--primary-foreground`, `--secondary-foreground`, etc., provide good contrast with their respective background colors.
    *   Remove dark mode variables as requested.
3.  **Update `tailwind.config.js`:**
    *   Verify that `theme.extend.colors` (e.g., `primary.DEFAULT`, `secondary.DEFAULT`, `destructive.DEFAULT`, `accent.DEFAULT`, `neutral.*`) correctly reference the updated CSS custom properties from `src/index.css` (e.g., `primary: { DEFAULT: 'hsl(var(--primary))' }`).
    *   Add direct Hbada color references to make development easier.
    *   Add `black` to the neutral color palette.
    *   Confirm `fontFamily.heading` is `['Montserrat', 'Arial', 'Helvetica', 'sans-serif']` and `fontFamily.body` is `['Roboto', 'Arial', 'Helvetica', 'sans-serif']` as per `CODEBASE_OVERVIEW.md`.
4.  **Verify Typography Application:** Check that base HTML elements (`body`, `h1-h6`, `p`) in `src/index.css` correctly apply these font families and that font weights/sizes are appropriate for the new design.
5.  **Test:** After changes, view the site locally. Check global background, text colors, and default heading/paragraph styles to ensure they reflect the new black/white/red theme.

## Progress
