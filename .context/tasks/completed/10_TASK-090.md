# TASK-090: Redesign CartPage Component (Hbada Clone Redesign)

## Description
This task involves redesigning the `CartPage.tsx` component to align its visual appearance with the Hbada clone site aesthetic. This includes styling the list of cart items, summary section (subtotal, shipping, total), and call-to-action buttons (e.g., "Proceed to Checkout") using the new black/white/red color palette.

## Objectives
- Restyle the cart item display (product image, name, price, quantity adjuster, remove button) for clarity and consistency with the new theme.
- Update the styling of the cart summary section, ensuring totals are clearly presented.
- Redesign the primary "Proceed to Checkout" button to use the new red accent color and appropriate typography.
- Style any secondary actions (e.g., "Continue Shopping" button, discount code input) consistently with the new theme.
- Ensure the overall layout of the cart page is clean, responsive, and matches the clone's design principles.

## Steps
1.  **Reference Clone Design:** Analyze screenshots or the live clone site (if it has a visible cart page design) to understand its cart page styling (item layout, summary box, button styles, typography).
2.  **Modify `CartPage.tsx`:**
    *   Update styling for individual cart item rows/cards: ensure product images, names, prices, and quantity adjusters use semantic classes and the new theme colors.
    *   Restyle "Remove from cart" buttons/icons, possibly using a subtle destructive color or neutral style.
    *   Style the cart summary box (background, borders, text colors for labels and values) using neutrals and clear typography.
    *   Redesign the main "Proceed to Checkout" CTA button to be prominent, using the primary red accent (e.g., `bg-primary text-primary-foreground`).
    *   Style any discount code input fields and apply buttons according to the new theme's form styling.
    *   Ensure consistent padding and spacing throughout the cart page.
3.  **Responsive Design:** Test the cart page on various screen sizes to ensure it remains usable and visually appealing.
4.  **Test Functionality:** Verify that quantity adjustments, item removal, discount code application (if applicable), and proceeding to checkout all function correctly. Ensure all data from `CartContext` is accurately displayed and interactions update the context as expected.
