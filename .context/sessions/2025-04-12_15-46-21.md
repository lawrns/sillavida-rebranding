# Fix Account Button Navigation

## Focus
Fix the account button in the navbar to properly navigate to the login page when clicked by a non-logged-in user.

## Context
The user reported that the account button in the navbar doesn't lead anywhere when clicked. After investigating, I found that the AccountButton component was calling a login() function directly instead of navigating to the login page.

## Progress
1. Identified the issue in the AccountButton.tsx component:
   - When a user is not logged in, clicking the account button calls the handleLogin() function
   - The handleLogin() function was trying to call a login() function from the customerAuth service
   - This function doesn't navigate to any page, so the user stays on the current page

2. Modified the AccountButton.tsx component:
   - Changed the handleLogin() function to navigate to the /login page instead of calling the login() function
   - Used window.location.href to ensure a full page navigation to the login page

## Decisions
- Used window.location.href instead of React Router's navigation to ensure a clean state when loading the login page
- Kept the existing dropdown functionality for logged-in users

## Self-Improvement
- This issue highlights the importance of consistent navigation patterns across the application
- It reinforces the need for centralized routing configuration and route consistency tests as planned in TASK-018 and TASK-019
- The issue was discovered through visual testing, which shows the importance of UI testing in addition to code testing

## Dependencies
- This change is related to the route consistency issues fixed earlier
- The account functionality depends on proper routing to the login, register, and account pages

## Next Steps
- Implement route consistency tests (TASK-018)
- Create centralized routing configuration (TASK-019)
- Consider adding UI tests to verify navigation functionality

## Notes
- The login() function in the customerAuth service might still be useful for programmatic login, but it should not be used for UI navigation
- This change improves the user experience by providing a clear path to login when clicking the account button
