# Fix Cart Functionality in Hero Slider

## Focus
Fix the issue with the "COMPRAR AHORA" (Buy Now) button in the HeroSlider component not adding products to the cart.

## Context
The user reported that when trying to add something to the cart, it doesn't work. After investigating, I found that the "COMPRAR AHORA" button in the HeroSlider component was not functional. It was just a button without any onClick handler to add products to the cart.

## Progress
1. Examined the CartContext.tsx file to understand how the cart functionality is implemented:
   - The CartContext provides an addItem function that takes a merchandiseId and quantity
   - The addItem function handles both creating a new cart and adding to an existing cart

2. Examined the ProductCard.tsx component to see how the add to cart functionality is implemented:
   - The ProductCard component uses the useCart hook to get the addItem function
   - It has loading and success states to provide visual feedback
   - It calls the addItem function when the "Agregar al Carrito" button is clicked

3. Updated the HeroSlider.tsx component to add cart functionality:
   - Imported the useCart hook from the CartContext
   - Added state variables for loading and success states
   - Created a handleAddToCart function to add the current slide's product to the cart
   - Added mock Shopify variant IDs for the slider products
   - Updated the "COMPRAR AHORA" button to call the handleAddToCart function when clicked
   - Added visual feedback for loading and success states

4. Created a decision document to document the changes:
   - Documented the issue and the solution
   - Documented the alternatives considered
   - Documented the rationale for the chosen solution
   - Documented the implications and follow-up actions

## Decisions
- Used the same pattern as the ProductCard component for consistency
- Added mock Shopify variant IDs for the slider products
- Implemented loading and success states for visual feedback
- Kept the direct add-to-cart functionality rather than linking to product pages

- It reinforces the need for consistent patterns across the application
- It demonstrates the value of having a well-designed context system for shared functionality
