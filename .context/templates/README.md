# Templates

This directory contains templates for various document types used in the Aegis framework. These templates ensure consistency in document structure and content across the project.

## Directory Structure

- `tasks/`: Templates for task documents
- `sessions/`: Templates for session records
- `decisions/`: Templates for decision records

## Usage

Templates are used by the Aegis framework when creating new documents. For example, when creating a new task, the framework will use the task template as a starting point.

### Task Template

The task template (`tasks/TEMPLATE.md`) defines the structure for task documents, including:
- Front matter with metadata
- Description
- Objectives
- Steps
- Progress tracking
- Dependencies
- Test status
- Notes
- Next steps

### Session Template

The session template (`sessions/TEMPLATE.md`) defines the structure for session records, including:
- Front matter with metadata
- Focus areas
- Context
- Progress
- Decisions
- Self-improvement insights and recommendations
- Dependencies
- Next steps
- Notes

### Decision Template

The decision template (`decisions/TEMPLATE.md`) defines the structure for decision records, including:
- Front matter with metadata
- Context
- Options considered
- Decision made
- Consequences
- Notes

## Customization

These templates can be customized to better fit the specific needs of the project, but should maintain the core structure to ensure compatibility with the Aegis framework.
