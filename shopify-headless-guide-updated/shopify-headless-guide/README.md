## Quick Start

This guide is designed for website owners who:
- Already have a landing page and want to keep full control over it
- Want to use Shopify to manage products, inventory, checkout, and other e-commerce features
- Need to link to product pages from their landing page without Shopify controlling the landing page design

Follow the documents in order for a complete understanding, or jump to specific sections based on your needs.

## For Anthropic Claude API Users

If you're using Anthropic's Claude API via the command line to work on this integration, you can use the code examples provided in the [Code Examples](code-examples.md) document. The examples include a section specifically for using Claude to generate product descriptions or other content for your e-commerce site.
