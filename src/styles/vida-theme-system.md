# SillaVida "Vida" Theme System

## Overview

The "Vida" theme is a key component of the SillaVida brand identity, reinforcing the "investing in yourself" concept through subtle organic visual elements that evoke life, growth, and wellness. This document defines the visual language and usage guidelines for the "Vida" theme integration across the SillaVida website.

## Core Concept

The "Vida" (Life) concept emphasizes that choosing the right chair is an investment in your life, health, and wellbeing. The visual elements of the "Vida" theme should convey:

- **Growth and vitality**: Organic shapes, gentle curves, and natural patterns
- **Balance and harmony**: Symmetrical elements with asymmetrical accents
- **Wellness and comfort**: Soft edges, flowing lines, and breathing space
- **Quality and durability**: Refined details and thoughtful touches

## Logo Treatment

### "Vida" Emphasis

The SillaVida logo should be updated to visually emphasize the "Vida" portion:

- **Silla**: Regular weight, slightly muted color
- **Vida**: Bold weight, vibrant teal color, subtle organic flourish
- **Optional**: Small leaf or growth element integrated into the "V" of "Vida"

### Usage Guidelines

- Maintain clear space around the logo equal to the height of the "V" in "Vida"
- Never stretch, distort, or rotate the logo
- Ensure the "Vida" emphasis is maintained in all applications
- For dark backgrounds, use the reverse color treatment while maintaining the "Vida" emphasis

## Organic Patterns

### Pattern Library

The "Vida" theme includes a library of organic patterns for backgrounds, dividers, and accents:

1. **Growth Pattern**: Subtle upward-flowing lines resembling plant growth
2. **Leaf Texture**: Abstract, minimalist leaf-inspired texture
3. **Wave Pattern**: Gentle, flowing waves suggesting comfort and ergonomics
4. **Cellular Pattern**: Hexagonal pattern inspired by natural cellular structures
5. **Breathing Pattern**: Expanding and contracting circular pattern suggesting breath and life

### Usage Guidelines

- Use patterns as subtle backgrounds at 5-15% opacity
- Apply patterns as section dividers at 20-30% opacity
- Ensure patterns don't compete with or obscure content
- Scale patterns appropriately for different screen sizes
- Combine patterns thoughtfully - don't use more than two patterns in close proximity

## Custom Icons

### Icon Style

The "Vida" theme includes custom icons with life/growth themes:

- **Style**: Line-based with organic touches, 2px stroke width
- **Corners**: Slightly rounded corners (2px radius)
- **Accents**: Small leaf or growth element where appropriate
- **Animation**: Subtle growth or breathing animations on hover

### Icon Categories

1. **Ergonomic Benefit Icons**: Representing posture, comfort, and health benefits
2. **Feature Icons**: Representing adjustability, materials, and technical features
3. **Experience Icons**: Representing wellness, productivity, and lifestyle benefits
4. **Navigation Icons**: Custom versions of standard navigation icons with organic touches

### Usage Guidelines

- Maintain consistent size and style across icon sets
- Use icons to reinforce text, not replace it
- Ensure icons are recognizable at small sizes
- Provide appropriate alt text and ARIA labels for accessibility

## Organic Elements

### Dividers

- **Growth Divider**: Upward-flowing lines resembling plant growth
- **Wave Divider**: Gentle, flowing waves suggesting comfort
- **Leaf Divider**: Subtle leaf-inspired separator
- **Breathing Divider**: Expanding and contracting circular pattern

### Backgrounds

- **Subtle Texture**: Light organic texture at 5-10% opacity
- **Gradient Overlay**: Gentle gradient with organic shape influence
- **Pattern Background**: Strategic use of the pattern library at low opacity

### Decorative Elements

- **Corner Accents**: Subtle organic shapes for empty corners
- **Section Markers**: Small leaf or growth elements to mark section beginnings
- **Focus Indicators**: Custom focus states with organic influence

## Hover and Animation Effects

### Hover Effects

- **Growth Effect**: Subtle upward movement or expansion
- **Breathing Effect**: Gentle pulsing or breathing animation
- **Color Shift**: Transition to a more vibrant shade of the same color
- **Organic Reveal**: Reveal of subtle organic pattern or accent

### Animation Guidelines

- Keep animations subtle and purposeful
- Use easing functions that mimic natural movement
- Ensure animations complete within 300-500ms
- Respect user preferences for reduced motion

## Implementation Guidelines

### General Principles

- The "Vida" theme should be subtle and sophisticated, not overwhelming
- Visual elements should reinforce the content, not distract from it
- Maintain consistency across similar components and sections
- Ensure all elements are responsive and work across device sizes

### Technical Considerations

- Use SVG format for icons and patterns for better performance and scalability
- Implement animations with CSS where possible for better performance
- Optimize all graphic elements for file size and loading performance
- Ensure all elements work with the updated color palette and typography

### Accessibility Considerations

- Maintain sufficient contrast for all visual elements
- Provide text alternatives for meaningful graphics
- Ensure animations don't trigger vestibular disorders
- Test with screen readers and keyboard navigation

## Integration with Design System

The "Vida" theme builds upon and integrates with the existing design system:

- **Color Palette**: Uses the established color palette with emphasis on teal and sage
- **Typography**: Complements the typography system, particularly the Playfair Display elements
- **Components**: Enhances existing components without fundamentally changing their function
- **Spacing**: Respects the established spacing system while adding organic touches
